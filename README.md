# Movie Ratings API

Система рейтинга фильмов на Go. Разработан в рамках учебного проекта командой из 3 разработчиков.

## Возможности

- Натсройка параметров поиска по разичным харакетристикам
- Возможность оставить отзыва на имеющийся материал
- Рейтинговая система с расчетом средних оценок
- Р=Не строгая регистрация пользователя

## Технологический стек

- **Backend:** Go 1.21+ (локальная разработка)
- **База данных:** PostgreSQL (локальный сервер)
- **Аутентификация:** Cookie-based sessions
- **Деплой:** Локальный хостинг (для демонстрации)
