# Рейтинг фильмов (Movie Ratings)

Проект представляет собой веб-приложение для управления рейтингом фильмов, разработанное на языке Go.

## Требования

Для запуска проекта необходим установленный **Go** версии 1.21 или выше.

## Установка и запуск

1.  **Скачайте зависимости:**
    ```bash
    go mod download
    ```

2.  **Перейдите в директорию приложения:**
    ```bash
    cd app
    ```

3.  **Запуск приложения**

    *   **Способ 1: Компиляция и запуск бинарного файла**
        ```bash
        go build
        ./app
        ```

    *   **Способ 2: Прямой запуск без компиляции (рекомендуется для разработки)**
        ```bash
        go run .
        ```

После успешного запуска приложение будет доступно по адресу, который указан в консоли (например, `http://localhost:8080
