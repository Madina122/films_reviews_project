
1. `go mod download` - скачиваем все зависимости Go
2. `cd app` - переходим в папку app
3. `go build` - компилирует программу в бинарный файл `app`
4. `cd app` - переходим к созданному бинарному файлу
4. `go run .` - запускаем проект


## Подключение к бд
- в файле filling.go вставь свой пароль в строчке 257 (где происходит коннект с базой данных)
- в файле connect_with_db также замени пароль на свой, 17 строчка
